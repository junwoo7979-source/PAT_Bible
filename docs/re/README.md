## 🔧 "고칠 위치" 찾는 법

1. **여기(`re/`)에서 뭘 고칠지 정한다** → refact-01.md / bug-list.md
2. **그 기능이 어느 코드 파일인지 찾는다** → `docs/WORKFLOW.md` 의 각 기능 `관련 파일:` 표
3. **실제 코드를 연다** → `app/js/___.js` (+ 화면은 `app/index.html` 의 `s-___`)
4. **수정 후 기록한다** → `docs/실행내역서.md`
