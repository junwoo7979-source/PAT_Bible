# 음성 녹음 실시간 분석 구현 계획

## 목표

마이크 녹음 중 인식된 문장과 유사도를 즉시 화면에 표시하고, 녹음 종료 시에만 최종 판정한다.

## 변경 파일

- `app/index.html`: 실시간 분석 함수와 Web Speech API 이벤트 연결 추가
- `docs/실행내역서.md`: 구현 기능 기록
- `C:\Users\SAMSUNG\Desktop\ai\pat-1단계-기획설계-실행문서.md`: 설계와 결과 기록

## 구현 순서

1. `previewVoice()` 함수가 아직 없고 `onresult`에서 실시간 분석을 호출하지 않는 상태를 확인한다.
2. `previewVoice(text)`를 추가해 유사도 막대, 유사도 문구, 재시작 버튼만 갱신한다.
3. `onresult`에서 인식 문장을 표시한 직후 `previewVoice(t)`를 호출한다.
4. 기존 `evalVoice(text)`는 `previewVoice(text)` 결과를 사용해 녹음 종료 후 통과 여부를 한 번만 판정한다.
5. 정적 검색, JavaScript 문법 검사, HTTP 응답으로 반영을 확인한다.

## 검증 기준

- `onresult`에서 `previewVoice(t)`를 호출한다.
- `previewVoice()`는 유사도 UI와 재시작 버튼을 갱신한다.
- `evalVoice()`에서만 다음 단계 활성화와 통과 토스트가 실행된다.
