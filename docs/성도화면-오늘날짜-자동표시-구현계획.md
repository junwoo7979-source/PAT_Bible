# 성도 화면 오늘 날짜 자동 표시 구현 계획

## 목표

성도 화면에서 접속한 오늘 날짜 기준 주간 기간과 오늘 날짜·요일을 자동 표시한다.

## 변경 파일

- `app/index.html`: 오늘 날짜 표시 요소와 렌더링 함수 추가
- `tests/week-period.test.cjs`: 오늘 날짜 문구와 성도 화면 반영 테스트 추가
- `docs/실행내역서.md`: 구현 결과 기록
- `C:\Users\SAMSUNG\Desktop\ai\pat-1단계-기획설계-실행문서.md`: 설계와 결과 기록

## 구현 순서

1. 오늘 날짜 문구 생성 함수가 없는 상태를 테스트로 확인한다.
2. 가족방과 구절 화면에 오늘 날짜 표시 요소를 추가한다.
3. `formatTodayLabel(dateValue)`를 추가한다.
4. `renderMemberDateLabels(dateValue)`에서 오늘 기준 주간 기간과 오늘 문구를 함께 반영한다.
5. 가족방과 구절 화면 렌더링에 공통 함수를 연결한다.
6. 날짜 테스트, 음성 회귀 테스트, 문법 검사, HTTP 응답을 실행한다.

## 검증 기준

- `2026-06-02` 입력 시 `오늘은 6월 2일 화요일입니다`를 반환한다.
- 성도 가족방과 구절 화면에 오늘 기준 주간 기간이 표시된다.
- 성도 가족방과 구절 화면에 오늘 날짜·요일이 표시된다.
