# 현황 화면 교구별 진행 표 구현 계획

## 목표

현황 페이지의 교회 전체 현황 위에 1·2·3블레싱 교구별 진행률 표를 표시한다.

## 변경 파일

- `app/index.html`: 교구별 현황 카드, 집계 데이터, 렌더링 함수 추가
- `tests/parish-dashboard.test.cjs`: 교구별 표 렌더링 테스트
- `docs/실행내역서.md`: 구현 결과 기록
- `docs/CLAUDE_CODE_인수인계.md`: 인수인계 업데이트

## 검증 기준

- 현황 화면에 `교구별 현황` 카드가 `교회 전체 현황`보다 먼저 표시된다.
- `1블레싱`, `2블레싱`, `3블레싱`이 모두 표시된다.
- 가족방의 교구와 일치하는 행에 `내 교구` 표시가 붙는다.
- 암송 완료 기록이 있으면 내 교구 완료 인원이 1명 증가한다.
