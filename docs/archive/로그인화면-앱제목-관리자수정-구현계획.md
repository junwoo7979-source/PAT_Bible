# 로그인 화면 앱 제목 관리자 수정 구현 계획

## 목표

관리자가 로그인 화면 상단 제목을 수정하고 새로고침 후에도 유지할 수 있게 한다.

## 변경 파일

- `app/index.html`: 로그인 제목 요소, 관리자 입력칸, 저장·복원 함수 추가
- `tests/app-title.test.cjs`: 제목 저장·복원 테스트
- `docs/실행내역서.md`: 구현 결과 기록

## 구현 순서

1. `saveAppTitle()`과 `pat_app_title` 복원 로직이 없는 상태를 테스트로 확인한다.
2. 로그인 제목에 `loginAppTitle` ID를 추가한다.
3. 관리자 교회 정보 카드에 `inAppTitle` 입력칸과 저장 버튼을 추가한다.
4. `APP_TITLE_DEFAULT`과 `applyAppTitle()`을 추가한다.
5. `saveAppTitle()`에서 입력값을 검증하고 localStorage 저장 후 로그인 제목을 갱신한다.
6. 초기화와 관리자 화면 렌더링에서 저장된 제목을 복원한다.
7. 앱 제목 테스트, 기존 날짜·음성 테스트, 문법 검사, 서버 반영 검사를 실행한다.
