# 가족방 대표 이름·구역 등록 구현 계획

## 목표

가족 대표가 홈 화면에서 가족방 등록을 열고 대표 이름과 구역을 저장할 수 있게 한다.

## 변경 파일

- `app/index.html`: 가족방 등록 화면, 홈 버튼, 저장·복원 함수 추가
- `tests/family-profile.test.cjs`: 대표 이름·구역 저장·복원 테스트
- `docs/실행내역서.md`: 구현 결과 기록
- `docs/CLAUDE_CODE_인수인계.md`: Claude Code 인수인계 업데이트

## 구현 순서

1. `saveFamilyProfile()`이 없는 상태를 실패 테스트로 확인한다.
2. 홈 카드에 대표 이름·구역 표시 영역과 `가족방 등록` 버튼을 추가한다.
3. `s-family-register` 화면에 대표 이름과 구역 입력 필드를 추가한다.
4. `loadFamilyProfile()`, `saveFamilyProfile()`, `renderFamilyProfile()`을 구현한다.
5. 홈 화면 렌더링 시 저장 값을 표시한다.
6. 가족 프로필 테스트, 기존 제목·날짜·음성 테스트, 문법 검사, HTTP 응답을 실행한다.

## 검증 기준

- 대표 이름과 구역을 입력하지 않으면 저장하지 않는다.
- 입력 후 저장하면 `pat_family_profile` localStorage에 저장한다.
- 홈 카드에 대표 이름과 구역을 표시한다.
- 저장된 값을 다시 읽어 등록 화면 입력 필드에 복원한다.
