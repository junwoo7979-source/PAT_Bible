# 100% 미만 전체 재시작 구현 계획

## 목표

음성 또는 타이핑 유사도가 100%가 아닐 때 사용자가 암송 과정을 음성 1차부터 다시 시작할 수 있게 한다.

## 변경 파일

- `app/index.html`: 음성·타이핑 화면 재시작 버튼, 공통 초기화 함수, 노출 조건 추가
- `docs/실행내역서.md`: 구현 결과 기록
- `_assets\docs\pat-1단계-기획설계-실행문서.md`: 작업 로그 기록

## 구현 순서

1. 현재 HTML에 `처음부터 다시 시작하기` 버튼이 없음을 검색하여 실패 상태를 확인한다.
2. 음성·타이핑 화면에 숨김 상태의 재시작 버튼을 추가한다.
3. `restartMemorize()`를 추가하여 `resetMemorizeState()`, 음성 화면 렌더링, 음성 화면 이동을 순서대로 실행한다.
4. 음성 평가 결과와 타이핑 입력 결과가 `100%` 미만이면 버튼을 표시하고, `100%`이면 숨긴다.
5. 화면 렌더링 시 버튼을 숨겨 이전 결과가 남지 않게 한다.
6. 정적 검색과 브라우저 응답으로 변경을 확인한다.

## 검증 기준

- 음성 화면과 타이핑 화면에 재시작 버튼이 존재한다.
- `restartMemorize()` 실행 시 음성 1차로 돌아간다.
- 음성·타이핑 유사도 `100%` 미만에서 버튼이 표시된다.
- 유사도 `100%`에서는 버튼이 숨겨진다.
