## 1. 프로젝트 개요
- **PAT Bible**: 교회·가족·개인 성경 암송 웹앱 (세광교회 디지털 사역)
- 핵심 흐름: 교회입장 → 가족방 → 구절 → **음성2회 + 타이핑2회 (4중 검증)** → 완료 → 현황
- 단일 파일 프로토타입: `app/index.html` (HTML+CSS+JS 일체형, localStorage 저장)
- 저장소: https://github.com/junwoo7979-source/PAT_Bible

## 3. 구현 완료 기능 (2026-06-02 기준)
### 성도
- 교회 코드 입장 / 로그인·로그아웃(홈·설정)
- 가족방: 대표·교구·구역 표시(`대표 OOO N교구 N구역`), 가족방 등록/이름 수정
- 가족 비밀번호: 초기엔 교회 코드, 가족 전용 비번으로 변경 가능
  - **가족 비번 설정 시 공용 교회코드로 그 가족방 입장 차단 (가족 외 접근 불가)**
- 구절 보기 / 오늘 날짜·주간 기간 자동 표시 (일요일→**주일** 표기)
- 음성 암송 1·2차 (실시간 STT + 유사도), 마이크 오류 시 대체 입력
- 타이핑 1·2차 (복사 차단, 정규화 비교), 진행 단계 바(4단계)
- 100% 미만 시 처음부터 재시작
- 완료·뱃지, 대시보드(개인/가족/교구/교회)
- 현황: 교구별 현황(1·2·3교구 + 블레싱 총합) 한 줄 압축 표

### 관리자
- 구절 입력(요절/요절내용), 교회 이름 관리, 로그인 앱 제목 수정
- 성도 화면 미리보기, 주간 기간 자동 설정, 등록 구절 목록·적용

## 4. 데이터 저장 키 (localStorage)
| 키 | 내용 |
|----|------|
| `pat_records` | 암송 완료 기록 배열 |
| `pat_verses` | 관리자 등록 구절 목록 |
| `pat_church_name` | 교회 이름 |
| `pat_family_profile` | 가족방 정보 {roomName, leaderName, parish, district, familyPassword} |
| `pat_login_title` | 로그인 화면 앱 제목 |
