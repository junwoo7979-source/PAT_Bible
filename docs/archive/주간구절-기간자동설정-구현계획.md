# 주간 구절 기간 자동 설정 구현 계획

## 목표

관리자가 기준 날짜를 선택하면 월요일부터 일요일까지의 주간 범위와 월 기준 주차를 자동 계산해 구절 적용 기간으로 저장한다.

## 변경 파일

- `app/index.html`: 날짜 선택 필드, 주간 기간 계산 함수, 관리자 미리보기와 저장 연결
- `tests/week-period.test.cjs`: 자동 기간 계산 회귀 테스트
- `docs/실행내역서.md`: 구현 결과 기록
- `_assets\docs\pat-1단계-기획설계-실행문서.md`: 설계와 결과 기록

## 구현 순서

1. `formatWeekPeriod()`가 아직 없는 상태를 테스트로 확인한다.
2. 날짜 선택 필드 `inDate`를 추가한다.
3. `formatWeekPeriod(dateValue)`에서 월요일과 일요일을 계산하고 요일을 포함한 문구를 반환한다.
4. `updateWeekFromDate()`에서 날짜 변경 시 `inWeek`과 미리보기를 갱신한다.
5. 관리자 화면 진입 시 현재 날짜가 없으면 오늘 날짜를 기본값으로 설정한다.
6. 회귀 테스트, JavaScript 문법 검사, HTTP 응답으로 반영을 확인한다.

## 검증 기준

- `2026-06-03` 입력 시 `2026년 6월 1주차 · 6월 1일 월요일 ~ 6월 7일 일요일`을 반환한다.
- 관리자 화면에 기준 날짜 선택 필드가 존재한다.
- 날짜 변경 시 적용 주차와 미리보기가 갱신된다.
