# 가족방 교구·구역 분리 구현 계획

## 목표

가족방 등록에서 교구와 구역을 별도 입력하고 홈 카드에 함께 표시한다.

## 변경 파일

- `app/index.html`: 교구 입력 필드, 저장·복원·표시 로직 확장
- `tests/family-profile.test.cjs`: 교구·구역 분리 저장 테스트
- `database/firestore-schema.json`: 가족방 교구 필드 추가
- `docs/실행내역서.md`: 구현 결과 기록
- `docs/CLAUDE_CODE_인수인계.md`: 인수인계 업데이트

## 검증 기준

- `familyParish`와 `familyDistrict` 입력 필드가 각각 존재한다.
- 저장 데이터가 `{ roomName, leaderName, parish, district }` 구조를 사용한다.
- 홈 카드에 `대표 이름 · 교구 · 구역`을 표시한다.
- 등록 화면을 다시 열면 교구와 구역을 각각 복원한다.
