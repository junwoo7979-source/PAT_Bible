### **3️⃣ Android TWA 스플래시 제거**

**파일**: `pat-bible-twa/MainActivity.java`

```java
/* 변경 전 */
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    launchPWA();  // ❌ 즉시 실행하지만 UI가 보임
    finish();
}

/* 변경 후 */
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    
    // 스플래시 화면 제거 (테마에서 처리)
    setTheme(android.R.style.Theme_Translucent_NoTitleBar);
    
    // PWA로 즉시 리다이렉트 (지연 없음)
    launchPWA();
    finish();
}
```

**파일**: `pat-bible-twa/AndroidManifest.xml`

```xml
<!-- 변경 전 -->
<activity
    android:name=".MainActivity"
    android:theme="@style/LaunchTheme">  <!-- ❌ 스플래시 테마 -->

<!-- 변경 후 -->
<activity
    android:name=".MainActivity"
    android:theme="@style/Theme.PatBibleApp">  <!-- ✅ 일반 테마 -->
```
