# 📖 PAT Bible 사용 설명서

> **성경 암송 검증 앱** — 음성 인식으로 정확하게, 함께 즐겁게

---

## 📱 1단계: 앱 설치하기

### 🌐 웹에서 시작하기

**PC 또는 모바일 브라우저에서:**

1. 다음 주소로 접속합니다
   ```
   https://pat-bible-app.web.app
   ```

2. 로그인 페이지가 표시됩니다
   ![로그인 페이지](../preview-login.png)

### 📲 모바일 앱으로 설치하기

**iPhone 사용자:**
1. Safari 브라우저에서 위 주소 접속
2. 하단의 **공유 아이콘** (⬆️) 탭
3. **"홈 화면에 추가"** 선택
4. **"추가"** 버튼 탭

**Android 사용자:**
1. Chrome 브라우저에서 위 주소 접속
2. 우측 상단의 **⋮** (더보기) 탭
3. **"홈 화면에 추가"** 선택
4. **"설치"** 또는 **"추가"** 버튼 탭

> 💡 **팁:** 앱으로 설치하면 오프라인에서도 이전 데이터를 볼 수 있습니다!

## 🔐 2단계: 교회 코드로 로그인하기

### ✅ 로그인 방법

1. **교회 코드** 입력 (관리자가 제공)
   - 예: `11111`
   
2. **가족 비밀번호** 입력
   - 처음 대표자가 가족방을 만들 때 설정한 번호
   - 예: `1234`

3. **[로그인]** 버튼 탭

![로그인 화면](../preview-login.png)

> ✓ 성공하면 **가족방 대시보드**가 열립니다

---

## 👨‍👩‍👧 3단계: 가족방 구성원 등록하기

### 📝 **대표자** (한 명만 — 예: 아버지)

#### 3-1단계: 가족방 만들기

1. 로그인 후 **"👑 대표 등록"** 버튼 탭
   
2. 다음 정보를 입력합니다:
   - **가족방 이름**: 예) "김가족", "이집안"
   - **대표자 이름**: 예) "김호태"
   - **교구**: 선택 (1교구, 2교구, 3교구, 블레싱)
   - **구역**: 자유 입력 (선택사항)
   - **가족 비밀번호**: 숫자 4자리 (예: `1234`)

3. **[가족방 등록]** 버튼 탭

![가족 등록 화면](../web-family-register.png)

> ✓ 가족방이 만들어집니다. 대표자는 자동으로 구성원에 추가됩니다.

---

### 👪 **다른 가족 구성원들** (아내, 아들, 딸 등)

#### 3-2단계: 가족 초대 링크로 입장

1. **대표자가 공유한 링크** 클릭
   - 예: `https://pat-bible-app.web.app/?code=11111&pw=1234`

2. 또는 직접 입력:
   - **교회 코드**: `11111`
   - **가족 비밀번호**: `1234` (대표자가 설정한 것)
   - **[로그인]** 탭

3. **"👨‍👩‍👧 가족 등록"** 버튼 탭

4. 본인 정보 입력:
   - **이름**: 예) "김미선"
   - **별명** (선택사항): 예) "엄마"

5. **[가족방 입장]** 버튼 탭

![가족 가입 화면](../web-family-register-fixed.png)

> ✓ 자동으로 "✓ 완료" 상태가 되며, 대시보드에 이름이 표시됩니다.

---

## 🔑 4단계: 비밀번호 변경하기 (선택사항)

가족 비밀번호를 변경하려면:

1. **가족방 입장** 후 화면 우측 상단의 **⚙️ 설정** 탭

2. **🔑 비밀번호 변경** 섹션에서:
   - **현재 비밀번호** 입력
   - **새 비밀번호** 입력 (4자리 숫자)
   - **[변경]** 버튼 탭

3. "비밀번호가 변경되었습니다" 메시지 확인

> ⚠️ **주의:** 새 비밀번호를 다른 가족들에게 알려줘야 나중에 입장할 수 있습니다!

---

## 🎯 5단계: 가족 초대 링크 공유하기

### 📤 다른 가족 구성원 초대

1. 가족방 입장 후 **우측 상단 설정(⚙️)** 탭

2. **📨 가족 초대** 섹션에서:
   - 초대 링크가 자동으로 생성됩니다
   - **[링크 복사]** 또는 **[공유]** 버튼 탭

3. 다음 중 하나 선택:
   - **카톡/문자로 공유**: 메시지에 붙여넣기
   - **링크 직접 알려주기**: URL 복사

### 📨 초대 링크 예시
```
https://pat-bible-app.web.app/?code=11111&pw=1234
```

> 💡 **팁:** 모든 가족이 같은 코드와 비밀번호로 입장합니다.

## 📖 6단계: 암송 시작하기

### ✍️ 암송 진행 순서

#### **1단계: 음성 1차 (마이크 사용)**

1. 가족방에서 **"📖 암송 시작"** 버튼 탭

2. 구절이 표시됩니다
   ```
   예: 요한일서 1:9
   "만일 우리가 우리 죄를 자백하면..."
   ```

3. 🎙️ **녹음 버튼** 탭
   - 마이크 권한 허용 팝업 표시
   - **[허용]** 또는 **[계속]** 탭

4. **"🔴 마이크 연결 중... 잠시 후 말씀하세요"** 표시 후
   - 구절을 **크고 명확하게** 읽으세요 (1-2분)

5. 말하기 종료 후 자동으로:
   - ✓ **유사도** 표시
   - 녹음된 내용 재생 가능

![음성 인식 화면](../preview-voice-mobile.png)

#### **2단계: 음성 2차**

1. 유사도가 **100%**가 아니면:
   - **[다시 검수]** 버튼으로 다시 녹음 가능

2. **유사도 100%** 도달하면:
   - **[다음 단계]** 버튼 활성화
   - 탭하여 진행

#### **3단계: 타이핑 1차**

1. 구절을 **텍스트로 입력**합니다
   - 마우스/터치로 자유롭게 타이핑
   - 진행률이 실시간 표시됨

2. **진행률 100%** 도달 후:
   - **[1차 완료 → 2차 진행]** 버튼 탭

#### **4단계: 타이핑 2차**

1. 다시 구절을 타이핑합니다
   - 이전 입력이 표시되지 않음 (재검수)

2. **진행률 100%** 도달 후:
   - **[완료 확인]** 버튼 탭

#### **✓ 완료!**

1. **완료 화면** 표시:
   ```
   요한일서 1:9 암송 성공
   
   음성 1차: 95%
   음성 2차: 100%
   타이핑 1차: 100%
   타이핑 2차: 100%
   ```

2. **[대시보드로 돌아가기]** 탭

![암송 완료 화면](../preview-prayer-screen.png)

### 🔄 **다시 검수하기**

완료 후에도 단계별로 다시 검수 가능:

1. 완료 화면에서 **"유사도 95% · 다시 검수"** 같은 버튼 탭
2. 해당 단계로 이동
3. **[다시 한번 하기]** 버튼으로 재녹음

## ❓ 자주 묻는 질문 (FAQ)

### Q1: 마이크가 안 됩니다
**A:** 
- 권한 설정 확인: 주소창 옆의 **🔒** 클릭
- **마이크** 권한을 **[허용]**으로 변경
- 앱 새로고침 (F5 또는 새로고침 버튼)

### Q2: 음성이 인식이 안 됩니다
**A:**
- 조용한 환경에서 다시 시도
- 크고 명확하게 읽으세요
- 텍스트 입력으로 대체 가능

### Q3: 진행률이 100%가 안 됩니다
**A:**
- 모든 글자가 입력되었는지 확인
- 구절을 정확하게 읽으세요
- **[다시 검수]** 버튼으로 재시도

### Q4: 비밀번호를 잊었습니다
**A:**
- 관리자(대표자)에게 문의
- 관리자는 **설정 > 비밀번호 변경**에서 새로 설정 가능

### Q5: 다른 기기에서 로그인할 수 있나요?
**A:**
- **YES!** 같은 교회 코드와 비밀번호로 로그인
- 모든 기기에서 동기화됨

### Q6: 오프라인에서 사용 가능한가요?
**A:**
- 앱으로 설치하면 **이전 데이터 조회 가능**
- 새로운 암송은 온라인에서만 등록 가능
