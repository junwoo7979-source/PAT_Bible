# PAT Bible — 교회별 사용 가이드 (멀티 교회)

> 각 교회는 **완전히 독립**적으로 운영됩니다. 다른 교회의 데이터에 접근할 수 없습니다.

---

## 👤 교회 관리자용 (최초 1회 설정)

### 1단계 — 교회 등록
1. 앱 첫 화면에서 **「🏛️ 새 교회 등록 (관리자)」** 버튼을 누릅니다.
2. 아래를 입력합니다.
   - **교회 이름** — 예: 은혜교회
   - **교회(교인 등록) 코드** — **특수문자 1개 + 숫자 6자리** (예: `#482913`)
     · 사용 가능한 코드인지 입력 즉시 확인됩니다.
   - **관리자 아이디** — 영문으로 시작하는 3~20자 (예: `pastorkim`)
   - **관리자 비밀번호** — **숫자 8자리** (예: `19450815`)
3. **「교회 등록하고 시작하기」** → 등록 완료 후 바로 관리자 화면으로 들어갑니다.

### 2단계 — 교인에게 코드 배포
- 등록 완료 시 안내되는 **교인 등록 코드(= 교회 코드)** 를 교인들에게 **카카오톡 등으로 공유**합니다.
- 예시 안내문(복사해서 보내세요):
  > [○○교회 성경암송] 앱 입장 코드: `#482913`
  > 앱에서 이 코드를 입력해 입장한 뒤, 가족방을 만들고 **본인 비밀번호**를 새로 정하세요.

### 다시 로그인할 때
- 첫 화면 **「🔐 교회 관리자 로그인」** → **교회 코드 + 아이디 + 비밀번호** 입력.

---

## 🙋 교인(가족)용

1. 앱 첫 화면의 입력칸에 관리자에게 받은 **교회 코드**(예: `#482913`)를 입력하고 **「시작하기」**.
2. 우리 교회 화면으로 들어갑니다.
3. **가족방 만들기** → 가족방 등록 시 **본인 비밀번호를 새로 설정**합니다.
   - 이 비밀번호로 우리 가족만 안전하게 분리됩니다.
4. 가족을 초대하려면 **초대 링크**를 공유하면 됩니다.

---

## ❓ 자주 묻는 질문

- **다른 교회 데이터가 보이나요?** — 아니요. 교회 코드로 완전히 분리되어 서로 접근 불가합니다.
- **코드를 잊었어요(관리자).** — 관리자 아이디/비번으로 로그인하면 관리자 화면에서 코드를 다시 확인할 수 있습니다.
- **세광교회는?** — 테스트 기간 동안 기존 방식(코드 비우고 `admin`/`1234`)을 그대로 사용하며, 추후 동일한 방식으로 전환됩니다.
