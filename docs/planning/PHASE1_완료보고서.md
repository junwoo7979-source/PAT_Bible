## 3. 산출물 상세

### ① 기능정의서 — `docs/기능정의서.md`
- MVP **9기능** (F1~F9) 입력·처리·출력·예외 정의
- 검증 임계값: 일반(음성85%/타이핑100%) · 관대(음성70%/타이핑90%)
- 3계층 권한: 교회관리자 / 가족대표 / 일반성도

### ② 화면 목록 (8화면)
| 화면 | 역할 |
|------|------|
| S1 로그인/시작 | 교회 코드 입력 |
| S2 교회 입장 | 교회 확인 |
| S3 가족방 | 구성원 달성률·초대 |
| S4 구절 보기 | 주간 구절 |
| S5 음성 암송 | STT 1·2차 |
| S6 타이핑 암송 | 직접 입력 검증 |
| S7 대시보드 | 개인/가족/교회 통계 |
| S8 설정 | 테마·접근성 |

### ③ 화면 설계도 + 테마
- `wireframes/index.html` — 8화면 와이어프레임 + 흐름도
- `design/theme-tokens.css` — 다크/크림 2종 + 접근성(큰 글씨) 토큰

### ④ DB 구조도 (Firestore 5컬렉션)
```
churches (교회) → families (가족) → users (사용자)
verses (구절)  → records (암송기록)
```
필드·타입·샘플데이터·인덱스 포함 → PHASE 4에서 그대로 사용 가능

## 5. 추가 성과 (PHASE 2 선행 착수)

계획상 PHASE 1은 설계까지지만, 설계 검증을 위해 **작동 프로토타입**을 선제 제작:
- `app/index.html` — 전체 흐름이 실제 동작하는 단일파일 웹앱
- 교회입장 → 가족방 → 구절 → 음성암송(STT) → 타이핑검증 → 완료 → 대시보드
- 설계가 실제로 동작함을 검증 완료 → PHASE 2 리스크 감소
