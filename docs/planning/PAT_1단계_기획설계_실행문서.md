## 1. 기능 명세서 (MVP 9기능)

> 1차 출시에 반드시 들어갈 9가지. 각 기능을 화면·데이터·우선순위와 함께 정의.

| # | 기능 | 설명 | 관련 화면 | 우선순위 |
|---|------|------|----------|---------|
| F1 | 🔑 교회 코드 입장 | 공용 코드 입력 → 소속 교회 확인, 가입 절차 제거 | 교회입장 | ★★★ |
| F2 | 👨‍👩‍👧 가족방 개설/초대 | 가족 코드 생성 → 구성원 초대, 비밀번호 보호 | 가족방 | ★★★ |
| F3 | 📖 주간 구절 등록 | 관리자가 주간 구절 등록 → 전 성도 실시간 동기화 | 구절보기/관리자 | ★★★ |
| F4 | 🎙️ 음성 암송(STT) | 구절 낭독 → 실시간 텍스트 변환, 1차+2차 검증 | 음성암송 | ★★★ |
| F5 | ⌨️ 직접 입력 검증 | 복사·붙여넣기 차단, 한 글자씩 → 100% 일치 통과 | 타이핑암송 | ★★★ |
| F6 | 🔥 실시간 진도 공유 | 완료 데이터 즉시 반영 + 푸시 알림 | 대시보드 | ★★ |
| F7 | 📊 성취도 대시보드 | 개인/가족/교회 일·주·월 차트 시각화 | 대시보드 | ★★ |
| F8 | 🏆 뱃지·암송왕 | 완료 시 뱃지, 주간 통계 기반 암송왕 집계 | 대시보드/완료 | ★ |
| F9 | 🌙 미니멀 UI | 광고 없는 크림/다크 모드, 큰 글씨, 전 연령 접근성 | 전체/설정 | ★★ |

**우선순위 범례**: ★★★ 필수(MVP 코어) · ★★ 중요 · ★ 부가(시간 여유 시)

## 2. 핵심 암송 워크플로우 (3중 검증)

> 사용자가 한 구절을 완료하기까지의 흐름. PHASE 3 구현의 기준.

```
[STEP 1] 음성 1차 암송      [STEP 2] 음성 2차 검증
 마이크 ON → 구절 낭독   →   같은 구절 재낭독
 STT 실시간 텍스트 변환       원문 vs 인식 유사도 분석
 (흐름 파악·소리내어 읽기)    (임계값 85% 이상 → 통과)
            │
            ▼
[STEP 3] 직접 입력          [STEP 4] 완료·공유
 복사·붙여넣기 차단      →   100% 일치 시 성공 뱃지
 한 글자씩 타이핑             기록 저장 + 실시간 동기화
 오타 시 즉시 빨간 표시       가족·교회 대시보드 반영
```

**설계 포인트**
- 음성 2회 + 타이핑 1회 = **3중 검증**으로 "진짜 암송" 보장
- 유사도 임계값·복사 차단은 **난이도 조절 가능**해야 함
- **노년층 배려**: 큰 글씨 + 관대 모드(임계값 낮춤)

## 3. 화면 목록 (8개)

> PHASE 2에서 v0.dev/bolt.new로 제작할 화면 단위.

| # | 화면명 | 역할 | 주요 요소 | 진입 경로 |
|---|--------|------|----------|----------|
| S1 | 로그인/시작 | 앱 진입점 | 교회코드 입력란, 시작 버튼 | 앱 최초 실행 |
| S2 | 교회 입장 | 교회 확인 | 코드 검증, 교회명 표시 | S1 → |
| S3 | 가족방 | 가족 단위 허브 | 가족 개설/입장, 구성원 목록, 달성률 | S2 → |
| S4 | 구절 보기 | 주간 구절 표시 | 이번 주 구절, 암송 시작 버튼 | S3 → |
| S5 | 음성 암송 | STT 1·2차 | 마이크 버튼, 인식 텍스트, 유사도 | S4 → |
| S6 | 타이핑 암송 | 직접 입력 검증 | 입력창(복사차단), 실시간 대조 | S5 → |
| S7 | 대시보드 | 통계·현황 | 개인/가족/교회 차트, 뱃지, 암송왕 | 하단 탭 |
| S8 | 설정 | 환경 설정 | 다크/크림, 글씨 크기, 관대 모드 | 하단 탭 |

**관리자 전용(확장)**: 주간 구절 등록, 성도 현황 통계, 엑셀 다운로드 → S4/S7에 관리자 모드로 통합

### 화면 흐름도
```
S1 로그인 → S2 교회입장 → S3 가족방 → S4 구절보기
                                          │
                              S5 음성암송 → S6 타이핑암송 → (완료)
                                          │
              [하단 탭] S7 대시보드 · S8 설정
```

## 4. 데이터 구조 설계 (Firestore 5개 컬렉션)

> PHASE 4(Firebase 연동)에서 그대로 사용할 DB 스키마.

### 4.1 `churches` (교회)
| 필드 | 타입 | 설명 |
|------|------|------|
| churchId | string | 교회 고유 ID (PK) |
| name | string | 교회명 (예: 세광교회) |
| accessCode | string | 공용 입장 코드 (예: 11111) |
| adminUids | array | 관리자 사용자 ID 목록 |
| createdAt | timestamp | 생성일시 |

### 4.2 `families` (가족)
| 필드 | 타입 | 설명 |
|------|------|------|
| familyId | string | 가족방 고유 ID (PK) |
| churchId | string | 소속 교회 ID (FK) |
| name | string | 가족방 이름 |
| password | string | 가족방 비밀번호(해시) |
| leaderUid | string | 가족 대표 사용자 ID |
| memberUids | array | 구성원 ID 목록 |
| createdAt | timestamp | 생성일시 |

### 4.3 `users` (사용자)
| 필드 | 타입 | 설명 |
|------|------|------|
| uid | string | 사용자 고유 ID (PK) |
| churchId | string | 소속 교회 ID (FK) |
| familyId | string | 소속 가족방 ID (FK) |
| name | string | 이름 |
| role | string | church_admin / family_leader / member |
| createdAt | timestamp | 가입일시 |

### 4.4 `verses` (구절)
| 필드 | 타입 | 설명 |
|------|------|------|
| verseId | string | 구절 고유 ID (PK) |
| churchId | string | 소속 교회 ID (FK) |
| reference | string | 성경 출처 (예: 요한복음 3:16) |
| text | string | 구절 본문 |
| weekOf | string | 적용 주차 (예: 2026-W23) |
| createdAt | timestamp | 등록일시 |

### 4.5 `records` (암송 기록)
| 필드 | 타입 | 설명 |
|------|------|------|
| recordId | string | 기록 고유 ID (PK) |
| uid | string | 사용자 ID (FK) |
| verseId | string | 구절 ID (FK) |
| familyId | string | 가족방 ID (FK) |
| churchId | string | 교회 ID (FK) |
| voiceScore1 | number | 음성 1차 유사도(%) |
| voiceScore2 | number | 음성 2차 유사도(%) |
| typingPassed | boolean | 타이핑 100% 통과 여부 |
| completedAt | timestamp | 완료일시 |
| badge | string | 지급된 뱃지 종류 |

### 데이터 흐름 (양방향)
```
교회 관리자 구절 등록 → 전 성도 동기화 → 개인 암송 완료
        ↑                                      │
        └── 교회 대시보드 집계 ← 가족방 실시간 반영 ┘
```
