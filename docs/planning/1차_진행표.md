## 4. 해결한 주요 버그

| 버그 | 원인 | 해결 |
|------|------|------|
| 관리자 등록 구절이 가족방에 안 보임 | 화면 전환 시 renderVerse 미호출 | go() 자동 렌더링 중앙화 + 가족방 구절 카드 |
| 음성 마이크 오류 | file:// 보안 차단, 이중 평가 버그 | 오류 가드 + 대체 입력 + 로컬서버 실행 |
| 타이핑 완료 버튼 미활성 | 띄어쓰기/문장부호/길이 과도 요구 | 정규화 비교(공백·부호 무시)로 변경 |

## 6. 실행 방법

### 마이크(음성) 정상 작동을 위한 로컬 서버 실행
```bash
cd C:\projects\PAT_Bible
python -m http.server 8000
```
브라우저: **http://localhost:8000/app/index.html**
> ⚠️ file://로 열면 마이크가 차단됨 — 반드시 localhost 사용
