# PAT Bible — 기능정의서 (확정본)

> PHASE 1 산출물 · MVP 9기능 · v0.dev/bolt.new 의뢰용 명세

---

## MVP 9기능 상세

### F1. 교회 코드 입장 ★★★
- **입력**: 공용 교회 코드 (예: 11111)
- **처리**: `churches.accessCode` 일치 검색 → 교회 확인
- **출력**: 교회명·성도 수 표시 후 입장
- **예외**: 코드 불일치 시 "존재하지 않는 코드" 안내
- **화면**: S1 → S2

### F2. 가족방 개설/초대 ★★★
- **개설**: 가족방 이름 + 비밀번호 설정 → `families` 생성, 개설자 = leader
- **초대**: 가족 코드/링크 공유 → 비밀번호 입력 후 `memberUids` 추가
- **화면**: S3

### F3. 주간 구절 등록 ★★★
- **권한**: church_admin 만
- **입력**: 출처(reference) + 본문(text) + 주차(weekOf)
- **처리**: `verses` 등록 → 전 성도 실시간 동기화(Firestore 리스너)
- **화면**: S4(조회) / 관리자 모드(등록)

### F4. 음성 암송 (STT) ★★★
- **1차**: 마이크 → 낭독 → Web Speech API 실시간 변환
- **2차**: 재낭독 → 원문 vs 인식 텍스트 **유사도 분석**
- **통과 기준**: 공백·문장부호 제거 후 일치율 **≥ 85%** (관대 모드 시 낮춤)
- **다음**: 2회 통과 시에만 F5(타이핑) 진입
- **화면**: S5

### F5. 직접 입력 검증 ★★★
- **차단**: 우클릭·Ctrl+V·드래그·붙여넣기 이벤트 차단
- **대조**: 입력 글자 vs 원문 글자 1:1 비교, 오타 즉시 빨간 표시
- **통과 기준**: **100% 일치** 시에만 완료
- **완료 처리**: 성공 뱃지 애니메이션 + `records` 저장 트리거
- **화면**: S6

### F6. 실시간 진도 공유 ★★
- **처리**: 완료 시 `records` 생성 → 가족·교회 대시보드 즉시 반영
- **알림**: 가족 구성원에 푸시 알림(선택)
- **화면**: S3 / S7

### F7. 성취도 대시보드 ★★
- **단위**: 개인 / 가족 / 교회
- **집계**: 일·주·월 차트
- **데이터원**: `records` 인덱스 집계
- **화면**: S7

### F8. 뱃지·암송왕 ★
- **뱃지**: 완료 시 종류별 지급 (`records.badge`)
- **암송왕**: 주간 통계 기반 자동 집계
- **화면**: S7 / 완료 모달

### F9. 미니멀 UI ★★
- **테마**: 다크 / 크림 2종 전환
- **접근성**: 큰 글씨, 관대 모드(노년층), 광고 없음
- **화면**: 전체 / S8(설정)

## 검증 임계값 정의 (난이도 조절)

| 모드 | 음성 유사도 기준 | 타이핑 기준 | 대상 |
|------|----------------|------------|------|
| 일반 | ≥ 85% | 100% 일치 | 일반 성도 |
| 관대(노년층) | ≥ 70% | 90% 일치 허용 | 노년층·접근성 |
