# 카카오 지속 인증 설계

## 목표

최초 카카오 로그인 승인 후 발급받은 토큰을 로컬 비공개 파일에 저장하고, 이후 발송은 재로그인 없이 처리한다.

## 구조

- `.kakao-tokens.json`: 액세스 토큰, 갱신 토큰, 만료시각을 저장하는 Git 제외 파일.
- `scripts/kakao-token-store.cjs`: 토큰 저장·조회·만료 판단 전담.
- `scripts/kakao-oauth.cjs`: 갱신 토큰으로 새 액세스 토큰을 요청하는 기능 추가.
- `scripts/kakao-local-oauth.cjs`: 최초 OAuth 성공 시 토큰을 저장한 뒤 메시지 발송.
- `scripts/kakao-send-authenticated.cjs`: 저장 토큰을 읽고, 필요하면 자동 갱신한 뒤 메시지 발송.

## 동작

1. 최초 승인 콜백에서 토큰과 만료시각을 `.kakao-tokens.json`에 저장한다.
2. 자동 발송 명령은 저장 토큰이 유효하면 즉시 사용한다.
3. 액세스 토큰이 만료됐으면 갱신 토큰으로 새 토큰을 받고 저장 파일을 갱신한다.
4. 갱신 토큰이 없거나 갱신이 실패한 경우에만 재로그인이 필요하다고 안내한다.

## 보안

- `.kakao-tokens.json`은 Git에서 제외한다.
- 토큰 원문은 콘솔, 문서, Git에 출력하지 않는다.
- 토큰 저장 파일은 프로젝트 로컬에서만 사용한다.

## 완료 조건

- 토큰 저장·조회·만료 판단 테스트 통과.
- 갱신 요청 형식 테스트 통과.
- 자동 발송이 유효 토큰과 만료 토큰 양쪽에서 동작.
- 최초 OAuth 콜백이 토큰 저장 후 발송.
