# PWA First Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make PAT Bible's current path explicitly PWA-first before a custom domain is connected.

**Architecture:** Keep the existing static web app and Firestore REST integration. Add install-ready PWA icon assets and verify all install metadata from lightweight Node tests.

**Tech Stack:** HTML, Web App Manifest, Service Worker, Node `assert`.

---

### Task 1: PWA Install Assets

**Files:**
- Modify: `app/manifest.json`
- Modify: `app/sw.js`
- Modify: `app/index.html`
- Create: `app/icons/pat-icon-192.png`
- Create: `app/icons/pat-icon-512.png`
- Create: `tests/pwa-assets.test.cjs`

- [ ] **Step 1: Write the failing test**

Create `tests/pwa-assets.test.cjs` to assert that the manifest includes PNG 192 and 512 icons, the service worker caches those PNG files, and the login page uses a PNG `apple-touch-icon`.

- [ ] **Step 2: Run test to verify it fails**

Run: `node tests\pwa-assets.test.cjs`

Expected: FAIL because the PNG icons are not registered yet.

- [ ] **Step 3: Add PNG icons and metadata**

Generate PNG icons from the existing SVG, register them in `manifest.json`, add them to `sw.js`, and update `apple-touch-icon`.

- [ ] **Step 4: Run test to verify it passes**

Run: `node tests\pwa-assets.test.cjs`

Expected: PASS.

- [ ] **Step 5: Run syntax checks**

Run:

```powershell
node --check app\sw.js
node -e "const fs=require('fs');const html=fs.readFileSync('app/index.html','utf8');const m=html.match(/<script>([\s\S]*?)<\/script>/);new Function(m[1]);console.log('app script syntax: PASS');"
```

Expected: both commands exit 0.
