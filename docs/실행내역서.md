## 12. 2026-06-03 음성 2차 마이크 꺼짐 방지

### 원인

- 음성 2차 진입 직후 브라우저 Web Speech API가 빈 결과로 `onend`를 보내면 앱이 즉시 수동 입력 박스를 띄웠다.
- 이 흐름이 사용자에게는 마이크가 바로 꺼지는 증상처럼 보였다.

### 구현 내용

- 빈 결과 `onend`가 발생하면 같은 단계에서 1회 자동 재시작한다.
- 자동 재시작 중에는 수동 입력 박스를 띄우지 않고 `마이크 준비 중... 잠시만 기다려주세요` 안내를 유지한다.
- 두 번째 빈 종료까지 발생하면 기존처럼 수동 입력 대체 경로를 제공한다.

### 검증

- `tests\voice-recognition-lifecycle.test.cjs`에 2차 음성 빈 결과 종료 후 자동 재시작 케이스를 추가했다.
- 전체 음성 생명주기 및 기존 PAT 테스트를 통과했다.

- 이전 유사도와 재검수 안내는 유지한다.

### 검증

- `tests\memorization-review.test.cjs`에 2차에서 1차 확인 후 다시 2차로 이동하는 케이스를 추가했다.

## 14. 2026-06-03 녹음 중 마이크 자동 복구 강화

### 원인

- 브라우저 Web Speech API는 무음, 네트워크 흔들림, 내부 세션 종료 때 `no-speech`, `network`, `aborted`, 빈 `onend`를 보낼 수 있다.
- 기존 구현은 일부 빈 종료만 복구했고, 오류 이벤트는 바로 수동 입력으로 전환했다.

### 구현 내용

- 녹음 중 일시 오류(`no-speech`, `network`, `aborted`)가 오면 수동 입력으로 떨어지지 않고 자동 재시작한다.
- 자동 복구 중에는 `마이크 준비 중... 잠시만 기다려주세요` 안내를 유지한다.
- 사용자가 마이크 버튼을 눌러 직접 중지한 경우에는 자동 복구하지 않는다.
- 무한 루프 방지를 위해 한 녹음 단계에서 최대 5회까지 자동 복구한다.

### 검증

- `tests\voice-recognition-lifecycle.test.cjs`에 `no-speech` 오류 후 자동 복구 케이스를 추가했다.
