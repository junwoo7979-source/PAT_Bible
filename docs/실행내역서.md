## 3. 프로토타입 앱 구현 기능 (app/index.html)

실제로 동작하도록 구현한 기능:

| 기능 | 구현 방식 |
|------|----------|
| 🔑 교회 입장 | 코드 검증(11111) → 화면 전환 |
| 👨‍👩‍👧 가족방 | 구성원 달성률 바·목록 렌더링 |
| 📖 구절 보기 | 주간 구절 데이터 표시 |
| 🎙️ 음성 암송 | Web Speech API STT + 레벤슈타인 유사도 검증(1·2차), 미지원 시 시뮬레이션 |
| ⌨️ 타이핑 검증 | 복사·붙여넣기 차단(onpaste/oncopy), 글자 1:1 대조(초록/빨강), 100% 일치 |
| 🏆 완료·뱃지 | 뱃지 애니메이션 + 점수 표시 |
| 📊 대시보드 | 개인/가족/교회 통계, localStorage 기록 저장 |
| 🌙 설정 | 다크/크림 테마, 큰 글씨, 관대 모드(기준 완화) |
| 🔄 전체 재시작 | 음성 또는 타이핑 유사도가 100% 미만이면 `처음부터 다시 시작하기` 버튼 표시 → 음성 1차부터 초기화 |
| ⚡ 실시간 음성 분석 | 마이크 녹음 중 인식 문장을 바로 표시하고 유사도 퍼센트·막대를 즉시 갱신, 녹음 종료 시 최종 판정 |
| 🎙️ 2차 음성 세션 안정화 | 1차 음성 종료 후 Web Speech API 핸들러와 참조를 해제하고, 새 녹음 시작 전 남은 세션을 정리 |
| 🛠️ 재시작 마이크 안정화 | 녹음 중 부분 인식에서는 재시작 버튼을 숨기고 최종 판정 후에만 표시, 재시작·새 녹음 시 마이크 UI 초기화 |
| ⏱️ 음성 API 해제 대기 | 이전 녹음 종료 직후 빠르게 마이크를 눌러도 `300ms` 해제 대기 후 자동 시작, `onstart` 수신 후 녹음 중 UI 표시 |
| 📅 주간 기간 자동 설정 | 관리자 기준 날짜 선택 → 월요일~일요일 기간과 월 기준 주차를 자동 계산해 미리보기·성도 화면·등록 목록에 표시 |
| 🗓️ 오늘 날짜 자동 표시 | 성도 가족방·구절 화면에서 접속한 오늘 날짜 기준 주간 기간과 `오늘은 M월 D일 요일입니다` 문구 표시 |
| ⛪ 홈 제목 PAT 표시 | 성도 홈 화면 상단 교회명을 `세광교회 PAT` 형식으로 표시 |
| ✏️ 로그인 앱 제목 수정 | 관리자가 로그인 화면 상단 `PAT Bible` 제목을 직접 변경하고 localStorage에 저장 |
| 👨‍👩‍👧 가족방 대표 등록 | 홈의 `가족방 등록`에서 대표 이름과 구역을 입력·저장하고 가족방 카드에 표시 |
| 🏠 가족방 이름 수정 | 가족방 등록 버튼을 주 버튼으로 활성화하고 등록 화면에서 가족방 이름을 수정·저장 |
| 🧭 교구·구역 분리 | 가족방 등록에서 교구와 구역을 별도 입력하고 홈 카드에 함께 표시 |
