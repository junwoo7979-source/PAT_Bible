## 4. 데이터 통합 (Firestore 단일 소스)

- **교구별 현황** (`75385b9`): 가족 등록 → 참가, 완료 → 진도. 관리자↔대시보드 일치.
- **시상관리** (`e8bb5fc`): 미완성 스텁(로컬·빈 데이터) → **가족별 실천율 순위**(getAwardRanking).
  실천율 = 완료 구절 수 / 총 구절 수. end-to-end(완료→100%) 검증.
- **등록가정** (`790414c`): 신규 관리자 탭 — 교회 전체 가족 목록(getFamiliesList).
  · 같은 Firestore 소스라 등록 즉시 교구별 현황 참가에 반영.
- 테스트 중복 가족 **초기화**: 15가정·21멤버·1기록 삭제 → 클린 슬레이트.
