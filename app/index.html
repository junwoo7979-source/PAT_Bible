홈 화면에 앱 설치

매번 주소 입력 없이, 홈 화면 아이콘으로 바로 실행하세요.
음성 기능도 더 안정적으로 동작합니다.

🤖 안드로이드 (Chrome)

  1. Chrome 브라우저로 이 페이지 열기
  2. 오른쪽 위 메뉴 (⋮) 누르기
  3. 「앱 설치」 또는 「홈 화면에 추가」 선택
  4. 홈 화면의 PAT 아이콘으로 실행

🍎 아이폰 / 아이패드 (Safari)

  1. Safari 브라우저로 이 페이지 열기
  2. 아래쪽 공유 버튼 (⬆️) 누르기
  3. 「홈 화면에 추가」 선택
  4. 홈 화면의 PAT 아이콘으로 실행

💬 카카오톡에서 열었다면

  1. 오른쪽 위/아래 메뉴 (⋮ 또는 …) 누르기
  2. 「다른 브라우저로 열기」 선택
  3. Chrome(안드로이드)·Safari(아이폰)에서 위 방법대로 설치

※ 카카오톡 안에서는 마이크·설치가 불안정하니 다른 브라우저를 권장합니다.
